 # Faol fuqaro — O‘zgarishlar tashabbuskori

9-sinf BSB-1 uchun o‘zbek tilidagi, to‘liq ekran va 3D o‘tish animatsiyalariga ega interaktiv taqdimot-sayt.

## Ishga tushirish

Bu statik sayt: framework, build bosqichi yoki server talab qilmaydi. index.html faylini brauzerda ochish kifoya.

## Cloudflare Pages orqali joylash

1. Cloudflare boshqaruv panelida **Workers & Pages → Create → Pages → Connect to Git** ni tanlang.
2. GitHub hisobingizni ulang va premiummaster156-cmd/tarbiya-presentation- repozitoriysini tanlang.
3. Production branch sifatida main ni belgilang.
4. Build command maydonini bo‘sh qoldiring.
5. Build output directory maydoniga . kiriting.
6. Deploy tugmasini bosing. Keyingi main commitlari avtomatik deploy qilinadi.

## Taqdimot boshqaruvi

- → / ←: keyingi yoki oldingi sahifa
- Sahifani surish: telefonda chapga/o‘ngga suring
- F yoki ⛶ tugmasi: to‘liq ekran
- Home / End: birinchi / oxirgi sahifa

## Muhim eslatma

So‘rov natijalari sahifasidagi diagramma shartli NAMUNA sifatida belgilangan. Himoyadan oldin uni jamoangiz o‘tkazgan anonim so‘rovning haqiqiy natijalari bilan almashtiring. Huquqiy ma’lumotlarni darslik yoki ishonchli manbalar orqali tekshiring.
